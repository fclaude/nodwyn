\chapter{Glossary}

\begin{description}[leftmargin=2.2em]
\item[binding] a user-owned row authorising a credential class for a
  destination, positions and methods; the egress authority.
\item[checker] one stage of the guard; reads a primitive's metadata and
  arguments, returns a verdict.
\item[control plane] the harness's own model; configured, and in the
  bootstrap unkeyed.
\item[data plane] every credential the user registers; bound and injected
  only at its destination.
\item[envelope] the bootstrap-era compensating controls, each retired by
  the phase that builds the real layer.
\item[handle] an opaque reference to a keychain entry; a Scheme value that
  can never become text.
\item[Jev] the external calibrated judge, admitted at Seam A (plans against
  asks) and Seam C (egress situations), over redacted content, never a
  secret value.
\item[origin] who initiated an evaluation: user or model.
\item[primitive] a Go handler in the table; the only way Scheme reaches the
  host.
\item[promotion] the gated copy of a candidate binary to \code{nibb-stable}.
\item[standing approval] a command prefix or write path the user authorised
  ahead of time; converts a confirm to an allow, never a deny.
\item[window] the model's context, rebuilt from the log on every request.
\end{description}
