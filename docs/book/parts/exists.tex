\section{Verified against the real control plane}

\begin{itemize}
\item ``Read \file{internal/log/log.go} and explain it'': the model read the
  file through the guard and answered correctly (13\,s cold prompt
  evaluation, 1.3\,s warm on the next request).
\item Two tool calls issued in one response, both executed.
\item \code{kill -9} mid-session; \code{nodwyn replay} reproduced the transcript,
  with no \code{session.end}.
\item An \code{fs-write} announced, confirmed with a diff, written.
\item The self-hosting acceptance: ``add a \code{string-reverse} builtin with
  a doc row and a conformance snippet, run the tests''\,---\,twice. Without
  \code{fs-edit}: 28 tool calls, 15 confirms, one mangled line repaired
  with ten shell calls, correct in the end. With it: 10 calls, 4 confirms,
  a clean nine-line diff.
\end{itemize}

\chapter{What is not there yet}

\begin{itemize}
\item No credential handling: no keychain, no bindings, no network primitive.
  The \code{KHandle} kind, the \code{credential} parameter role and the
  \file{bindings.toml} loader exist as seams.
\item No L3, and no ingress redaction yet (P7). \code{log.Writer.Filter} is
  the hook the redactor will occupy. L1 and L2 are built: shapes are
  detected on the way out, and every value carries a provenance tag that
  the guard reads at the egress edge.
\item No Jev, no plan gate. \code{gate.plan} is a declared event kind with
  no writer.
\item No session resume; the log has everything, the window is not yet
  rebuilt from a previous session's file.
\item No TUI; the plain front-end is the only one. The boundary lint keeps
  the core ready for another.
\item The window is naive by design; summaries and the structural index
  are P10.
\item A turn stops at fifty tool calls; budgets and checkpoints are
  \adr{18}, proposed.
\end{itemize}
